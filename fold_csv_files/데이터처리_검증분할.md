# 데이터 처리 — 검증 분할 방식

## 1. 요약

- 공식 검증셋은 **train의 fold 0 (1,344문항)** 입니다.
- 분할은 **이미지 해시(MD5) 기준 StratifiedGroupKFold 5-fold**로, 같은 이미지는 반드시 같은 fold에 들어갑니다.
- test와 같은 이미지를 가진 train 24문항은 **학습에서 제외**합니다.
- dev는 정답(교육생 5인 응답) 신뢰도가 낮아 **보조 참고용**으로만 씁니다.

## 2. 이미지 기준 (그룹 키)

| 항목 | 내용 |
|---|---|
| 그룹 키 | `img_hash` = 이미지 파일 바이트 전체의 MD5 해시 |
| 의미 | 파일명·질문이 달라도 파일 내용이 완전히 같은 이미지는 같은 그룹 |
| 이유 | 파일명 기준으로는 중복이 0건이지만, 해시 기준으로는 train 내부에 동일 이미지 7쌍(14행)이 존재. 파일명 기준 랜덤 분할 시 같은 이미지가 학습과 검증에 나뉘어 검증 점수가 부풀려짐 |
| 한계 | 리사이즈·크롭 등으로 조금이라도 바뀐 이미지는 다른 그룹으로 처리됨 (유사 이미지 검사는 미수행) |

## 3. 분할 설정

| 항목 | 값 |
|---|---|
| 방법 | `sklearn.model_selection.StratifiedGroupKFold` |
| fold 수 | 5 |
| stratify 기준 | `answer` (a/b/c/d) |
| group 기준 | `img_hash` |
| 재현 설정 | `shuffle=True, random_state=42` (scikit-learn 1.8.0) |
| 공식 검증 fold | **fold 0** |

## 4. 분할 결과

| fold | 문항 수 | a | b | c | d |
|---|---|---|---|---|---|
| 0 (검증) | 1,344 | 340 | 329 | 344 | 331 |
| 1 | 1,343 | 340 | 329 | 343 | 331 |
| 2 | 1,343 | 340 | 329 | 343 | 331 |
| 3 | 1,342 | 340 | 329 | 343 | 330 |
| 4 | 1,342 | 340 | 328 | 343 | 331 |

- 같은 이미지가 두 개 이상의 fold에 걸친 경우: **0건** (검증 완료)
- fold 0 이미지 해시와 fold 1~4 이미지 해시의 교집합: **0건** (검증 완료)

## 5. 겹침 이미지 처리

| 구분 | 건수 | 처리 |
|---|---|---|
| train 내부 동일 이미지 | 7쌍(14행) | 같은 fold로 묶음, 학습 사용 |
| train ↔ test 동일 이미지 (`overlap_test`) | 24행 (fold 0: 12, fold 1: 2, fold 2: 2, fold 3: 5, fold 4: 3) | **학습에서 제외**, 검증 fold에서는 그대로 평가 |
| train ↔ dev 동일 이미지 (`overlap_dev`) | 3행 | 학습 사용, 대신 dev 보조 평가에서 해당 dev 3문항 제외 |

train ↔ test 동일 이미지 24행을 학습에서 빼는 이유: 주최 측 제공 학습 데이터라 사용 자체는 문제가 없을 가능성이 높지만, test 이미지와 직접 연결된 정보를 학습하는 것은 오해 소지가 있고 제외해도 손실이 0.36%에 불과함. 또한 해시 일치 정보를 test 답 추정에 사용하지 않음.

## 6. dev 사용 방침

| 항목 | 수치 |
|---|---|
| 평가 가능 문항 (응답 1개 이상) | 2,681 |
| 동점(tie) | 465 (17.3%) |
| 최다 득표 합의율 중앙값 | 60% (5표 중 3표) |
| 4표 이상 합의 문항 | **0건** |
| 합의율 80% 이상 | 17건 (3명 응답 중 3표) |

교육생 응답이 4표 이상 일치한 문항이 한 건도 없어 다수결 정답의 신뢰도가 낮음. 따라서:

- 모델 선택·튜닝의 근거로 쓰지 않음
- 학습에 쓰지 않음
- 동점 없이 3표 합의 + train 겹침 제외 문항 **2,024건(`dev_aux.csv`)** 만 경향 확인용 보조 지표로 사용

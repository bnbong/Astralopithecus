- `21_colab_27b_run_20260921_A100-80GB_bf16_v1_image_only.ipynb`: 21번 노트북의 본 실행본입니다.
  fold 0 정확도는 원본이 0.9539였고 LoRA 학습 이후에 0.9568이 되었습니다. McNemar 검정의
  p값이 0.66이므로 두 값의 차이를 표본 변동과 구분할 수 없습니다. 원본에 p2 프롬프트를 쓴
  결과는 0.9591이었으며, 이 값도 v1 프롬프트와 비교하면 p값이 0.23입니다. 학습은 step당
  13.5초로 670 step을 돌았습니다. Kaggle public 점수는 학습 모델이 0.96544, 원본이
  0.95889였습니다.

## 2026-09-21 A100 측정값

| 구성 | microbatch | optimizer step | 문항당 추론 | peak VRAM | 정확도 |
|---|---|---|---|---|---|
| A100 40GB / nf4 | 7.95초 | 측정하지 않음 | 1.06초 | 28.0GB | zero-shot 0.9660 (폐기된 500문항 분할) |
| A100 80GB / bf16 | 6.39초 | 51.16초 | 0.91초 | 55.4GB | 50문항 확인 0.98 |

위 표에 적힌 nf4와 bf16의 preflight 측정값은 모두 TF32를 끈 상태에서 측정한 값입니다.
코드에 `runtime.tf32` 설정이 추가된 이후의 실행은 TF32가 켜진 상태이므로, 이 표의 수치와
직접 비교하려면 측정 조건이 달라졌다는 점을 함께 적어 주십시오.

40GB에서 측정한 0.9660은 지금은 폐기한 검증 500문항 분할에서 나온 값이라서, fold 0 기준
점수와 직접 비교하면 안 됩니다. bf16의 50문항 확인은 preflight가 돌린 표본 점검이며, 공식
검증 점수가 아닙니다.
